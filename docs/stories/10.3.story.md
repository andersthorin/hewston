# Story 10.3 — Enhanced Metrics & Analytics Engine

**Story ID**: S10.3  
**Epic ID**: E10  
**Status**: Ready

## User Story
As a **trading strategy developer**,  
I want **comprehensive trading metrics (PnL, win rate, Sharpe ratio, max drawdown) with a modular calculation system**,  
So that **I can evaluate strategy performance with professional-grade analytics and easily add custom metrics later**.

Third story of Epic 10. Builds on real Nautilus engine (S10.1) to extract comprehensive performance metrics from Nautilus backtest results. Creates modular system for future custom metrics while maintaining backward compatibility.

## Metrics Specifications

### Core Metrics (MVP)
1. **Total Return**: (final_value - initial_value) / initial_value
2. **Win Rate**: profitable_trades / total_trades  
3. **Sharpe Ratio**: (mean_return - risk_free_rate) / std_return
4. **Max Drawdown**: max((peak - trough) / peak) over time

### Future Extensible Metrics
- **Profit Factor**: gross_profit / gross_loss
- **Sortino Ratio**: downside deviation adjusted returns
- **Calmar Ratio**: annual return / max drawdown
- **Average Trade Duration**: mean time in position
- **Total Trades**: count of completed round-trip trades

### Risk-Free Rate Assumption
- Use 0% for Sharpe ratio calculation (conservative)
- Make configurable for future enhancement

## Risk Mitigation
- **Primary Risk**: Metrics calculation errors affecting backtest results
- **Mitigation**: Extensive unit testing with known expected values, gradual rollout
- **Rollback Plan**: Metrics calculation can fall back to existing simple calculations
