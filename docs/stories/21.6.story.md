# Story 21.6 — Seed Control and Reproducibility Toggle

Goal
- Allow user to set or lock random seed(s) for reproducible runs; expose a UI toggle.

Acceptance Criteria
- UI control to set seed or enable "reproducible mode"
- Seed(s) persisted in manifest and used by runner

Tasks
- Backend: accept/validate seed(s); plumb into runner
- Frontend: settings control and validation
- Tests

Dependencies
- Epics 16, 21; ADR-008
