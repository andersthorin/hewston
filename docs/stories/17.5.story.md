# Story 17.5 — Strategy Defaults and RTH/EOD Controls

Goal
- Define and validate default parameters and trading-session controls for new strategies.

Acceptance Criteria
- Defaults:
  - momentum: lookback 50; signal = ROC or slope; trade_size via sizing policy
  - rsi_mr: rsi_period 14; upper 70; lower 30
  - breakout: donchian 20
- Each strategy honors rth_only and eod_flat flags
- StrategyFactory validates params against pydantic schemas

Tasks
- Defaults + schema definitions
- rth_only/eod_flat handling in strategies
- Tests

Dependencies
- Stories 17.1–17.4; Epic 19 sizing hooks
