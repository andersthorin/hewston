# Story 13.3 — Frontend: Playback Metrics Panel

Status: Approved for Dev
Epic: Epic 13 — Relevant Backtest Metrics with Playback
Owner: FE

## Goal
Display read-only cumulative metrics during playback, updating in lockstep with the Playback Clock.

## Scope (In)
- Read from WS frames: `frame.metrics`
- Display fields: `return`, `realized_pnl`, `total_return`, `drawdown`, `sharpe`, `win_rate`
- Presentational-only component(s); data orchestration lives in containers/services
- No sorting/filtering

## Constraints
- No client-side recomputation of financial metrics
- Handle `null` values gracefully; show placeholders (—) or muted text
- Use existing design tokens and components

## Acceptance Criteria
- Metrics panel updates every frame while playing and on seek during pause
- Values format consistently (e.g., return/drawdown/total_return as %, sharpe with 2 decimals, realized_pnl with currency)
- Accessibility: keyboard focusable controls unaffected; metrics region readable

## Validation
- Manual QA script: play, pause, seek to several timestamps and verify values mirror backend frames
- Snapshot/visual tests: stable rendering of panel with sample frames

## Non-Goals (Out)
- Charts or trend plots for metrics (may be a future story)
- Any list/table integrations

## Implementation Notes (informative)
- Panel wiring listens to the central Playback Clock/store; derive display values from the latest frame
- Consider a small debounce to coalesce renders if needed (not more than 1 frame delay)
