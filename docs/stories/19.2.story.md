# Story 19.2 — Risk Constraints

Goal
- Implement exposure caps, EOD flatten, max drawdown stop, and daily trade cap.

Why
- Bound risk and avoid pathological behavior in backtests.

Acceptance Criteria
- Per-symbol and account-level exposure limits enforced
- Optional EOD flatten for intraday/quotes
- Max DD stop halts run when threshold breached
- Daily trade cap enforced

Tasks
- Constraint definitions and enforcement points
- Tests for each constraint

Dependencies
- Story 19.1; Epic 20 portfolio context
