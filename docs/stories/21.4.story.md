# Story 21.4 — Guardrail Thresholds Config UI

Goal
- Expose configurable guardrail thresholds (coverage %, min trades, turnover, max DD) in the admin UI.

Why
- Allow tuning realism and resource constraints without code changes.

Acceptance Criteria
- Admin-only settings surface with validation and sensible defaults
- Changes persisted and used by orchestrator
- Safe ranges and tooltips for guidance

Tasks
- Backend config endpoints and persistence
- UI form with validations
- Integration tests

Dependencies
- Epic 19 guardrail definitions; Epic 16 orchestrator
