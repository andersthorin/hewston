# Story 19.3 — Metrics Suite and Cost Model

Goal
- Compute KPIs and simulate costs (slippage/fees) for evaluation and ranking.

Why
- Enable robust comparison and guardrail checks.

Acceptance Criteria
- Metrics: Return, Ann.Vol, Sharpe/Sortino, MaxDD, Calmar, Hit rate, Profit factor, Turnover
- Cost model applied producing cost-adjusted PnL
- metrics.json persisted per run

Tasks
- Metrics calculators and integration
- Simple configurable cost model
- Tests with fixtures and tolerances

Dependencies
- Story 19.1, 19.2; Epic 20 integration
