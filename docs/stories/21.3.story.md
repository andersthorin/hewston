# Story 21.3 — History and Manifests UI

Goal
- Surface plan/guardrail manifests and code hashes in the UI for auditability.

Why
- Ensure reproducibility and traceability for all agentic runs.

Acceptance Criteria
- Run detail view shows manifest JSON (plan, guardrails, inputs, code hash)
- Diff view for successive runs (key changes)
- Download manifest

Tasks
- API to fetch manifests
- UI components for view/diff
- Tests

Dependencies
- Epic 16 persistence, Epic 19 guardrails/metrics
