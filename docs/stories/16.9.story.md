# Story 16.9 — Idempotency UX and Duplicate Plan Handling

Goal
- Provide clear UX for duplicate plan submissions (same plan_hash) and surface actionable messages.

Acceptance Criteria
- If start_agentic_run detects duplicate plan_hash, UI shows: "This plan was already submitted. Opening the existing run(s)."
- Navigates to existing run(s) detail; no new jobs queued
- Error states use standardized reason codes and are mapped to user-friendly copy

Tasks
- API response mapping for duplicate detection
- UI message and navigation behavior
- Tests

Dependencies
- Story 16.7 (plan_hash idempotency)
