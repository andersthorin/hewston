# Story 16.1 — UI: Agentic Mode Toggle and Date Range

Goal
- Add an Agentic Mode toggle to the create-run screen; preserve manual mode (symbol+strategy+dates).

Why
- Allow user to start agentic backtests by only selecting date range.

Acceptance Criteria
- Toggle present; OFF = manual controls visible and unchanged; ON = only date range required
- Client-side validation for date range
- Form state persisted on navigation

Tasks
- Add toggle + helper text
- Wire show/hide for manual fields
- Date range picker with validation
- Unit/UI tests

Dependencies
- None
