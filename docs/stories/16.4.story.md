# Story 16.4 — Backend: start_agentic_run Endpoint

Goal
- Implement POST /agentic/start to execute a previously proposed plan or a supplied plan payload.

Why
- User-triggered execution of the agentic plan with persisted manifests.

Acceptance Criteria
- Input: {plan_id} or full plan payload; validates guardrails again
- Creates one or multiple runs; persists run-manifest with plan + guardrail results + code hash
- Returns {run_ids[], manifests[]}

Tasks
- Controller + schema validation
- Service: transform plan to job requests
- Persist manifests and enqueue jobs
- Tests (happy path + guardrail rejections)

Dependencies
- Stories 16.2, 16.3; Epics 18, 19, 20
