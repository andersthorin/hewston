# Story 20.1 — Runner: Multiple Strategies per Symbol

Goal
- Extend NautilusBacktestRunner to run multiple strategy instances on one symbol in a single run.

Why
- Simulate interaction/competition for capital and improve realism.

Acceptance Criteria
- Runner accepts list of strategies and instantiates them for the same instrument_id
- Strategies added before data; OMS=HEDGING
- Artifacts captured and persisted

Tasks
- Runner API and implementation
- Tests with 2+ strategies on one symbol

Dependencies
- Epic 17, Epic 19
