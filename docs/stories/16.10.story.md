# Story 16.10 — Feature Flag and First-Time Consent

Goal
- Gate Agentic Auto-Selection with an admin feature flag and show a first-time consent prompt.

Acceptance Criteria
- Feature flag (admin-only) controls visibility of Agentic Mode toggle; default OFF
- First-time consent modal appears once per user and records acknowledgment
- Consent status persisted and respected by UI

Tasks
- Backend: feature flag exposure; per-user consent state
- Frontend: conditional UI + consent modal
- Tests

Dependencies
- Epic 21 Feature Flag and Consent (addendum)
