# Story 19.1 — Sizing Policies

Goal
- Implement volatility-normalized and fixed-size position sizing policies.

Why
- Comparable risk across symbols/strategies; stable behavior.

Acceptance Criteria
- Policy interface with two implementations (vol-normalized, fixed-size)
- Configurable targets (e.g., 10 bps/day), floors/ceilings
- Unit tests with deterministic inputs

Tasks
- Policy classes and config
- Utility to estimate volatility from data window
- Tests

Dependencies
- Epic 18 (data discovery for vol window)
