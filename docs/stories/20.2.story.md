# Story 20.2 — Runner: Small Multi‑Symbol Bundles + Streaming

Goal
- Support optional small multi‑symbol bundles per run and streaming mode for large ranges.

Why
- Scale towards multi‑symbol live/paper realism without exhausting resources.

Acceptance Criteria
- Runner accepts instrument_ids: list[str] and builds data configs accordingly
- Streaming=True processes data in chunks; memory-safe on M1
- Artifacts and metrics generated per run

Tasks
- BacktestRunConfig with multiple BacktestDataConfig entries
- Streaming flow validation
- Tests on 3–5 symbols with short range

Dependencies
- Story 20.1; Epics 18, 19
