# Story 13.1 — Backend: Precompute cumulative metrics from Nautilus series

Status: Approved for Dev
Epic: Epic 13 — Relevant Backtest Metrics with Playback
Owner: Dev (hand‑off from PO)

## Goal
Compute cumulative metrics for every timestamp of a finished run using only Nautilus outputs, and persist them in a single artifact at `metrics_path`.

## Scope (In)
- Inputs (from Nautilus):
  - returns series (per bar)
  - equity series (normalized account/equity values over time)
  - realized PnL series (USD)
  - optional raw analyzer stats (pnls/returns/general) for static summary
- Outputs:
  - A JSON artifact at `metrics_path` with:
    - `stats.raw`: opaque pass‑through of Nautilus analyzer stats
    - `series`: array of `[ts_iso, { equity, return, realized_pnl, total_return, drawdown, sharpe, win_rate }]`

## Constraints
- Source of truth is Nautilus; no external datasets.
- Cumulative‑to‑date metrics (no look‑ahead; no windowed variants in this story).
- Currency for realized PnL: USD.
- Annualization factor P is derived from the bar interval recorded in manifest (default 1m ⇒ P = 252 × 390).

## Definitions
- `return_t = equity_t / equity_{t-1} - 1`
- `total_return_t = equity_t / equity_0 - 1`
- `drawdown_t = (peak_to_date - equity_t) / peak_to_date` (≥ 0)
- `sharpe_t = sqrt(P) × mean(returns_1..t) / std(returns_1..t)` (r_f=0)
- `win_rate_t = wins_to_date / (wins_to_date + losses_to_date)` using realized PnL deltas per trade/step

Edge cases:
- std = 0 ⇒ `sharpe_t = null`
- division by zero ⇒ metric = null
- missing series ⇒ fields omitted or null

## Acceptance Criteria
- A completed run produces `metrics_path` with non‑empty `series` aligned to timestamps.
- Each item includes: `return`, `realized_pnl`, `total_return`, `drawdown`, `sharpe`, `win_rate`.
- P derived from manifest bar interval; default 1m ⇒ P≈98,280.
- Determinism: re‑running the precompute against the same inputs yields identical results within float tolerance (≤ 1e‑9 absolute).

## Validation & Tests
- Unit tests for Sharpe, drawdown, win rate on synthetic series (edge cases included).
- Integration test: a small sample run yields the expected `metrics_path` structure and monotone non‑decreasing `realized_pnl` except for flat segments.

## Non‑Goals (Out)
- Windowed/rolling Sharpe/Sortino.
- DB metrics normalization.
- FE rendering.

## Implementation Notes (informative)
- Read bar interval from manifest; compute P as `252 × (390 / bar_minutes)`.
- For win rate, treat realized PnL positive step as win, negative as loss; ignore zeros.
- Persist timestamps as ISO‑8601 UTC strings.
