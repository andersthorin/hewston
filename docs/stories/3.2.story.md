# Story 3.2 — Warehouse materialization (QuoteTicks→MID bars + Trades aggregates)
Story ID: S3.2
Epic ID: E3



Status: Ready for Review

User Story
- As a data engineer,
- I want to materialize deterministic MID 1-minute and 1-hour bars from QuoteTicks (TBBO) and aggregate Trades,
- So that backtests and the UI have reproducible, performant inputs stored in a warehouse (Parquet).

Context
- Replaces legacy derive step. Reads Databento DBN (TRADES+TBBO) and writes canonical warehouse Parquet (quotes, trades_agg, materialized MID bars).


Dependencies
- Depends on: S3.1 (ingest DBN)
- Blocks: S3.3 (catalog upsert), S4.1 (runner uses bars)

Acceptance Criteria
1) Running `make materialize-day SYMBOL=AAPL DATE=2024-10-01 VENUE=XNAS` performs materialization after ingest
2) Warehouse outputs written under repo-relative paths: `data/warehouse/{quotes, trades_agg/{1min,1h}, bars/mid_{1min,1h}}/venue=XNAS/symbol=AAPL/date=YYYY-MM-DD/`
3) Bars indexed by UTC; NAZDAQ calendar rules applied; UI will display America/New_York
4) Bars manifest JSON created alongside Parquet with fields: dataset_id, symbol, interval="1m", from_date, to_date, rebar_params, input_hashes, output_hashes, calendar_version, tz, created_at
5) Idempotent behavior: re-running with same inputs overwrites deterministically or no-ops (configurable), with identical hashes
6) Lint passes; no API handler involvement

Technical Specifications
- Implement/own three jobs:
  - `backend/jobs/quotes_ingest.py` TBBO DBN → QuoteTicks (Parquet)
  - `backend/jobs/trades_aggregate.py` Trades DBN → {1min,1h} aggregates (Parquet)
  - `backend/jobs/materialize_bars.py` QuoteTicks + Trades aggregates → MID bars {1min,1h} (Parquet)
- Use Polars/Pandas for transformations; PyArrow/Parquet IO

Tasks / Subtasks
- Implement transform functions: trades_to_bars_1m, tbbo_to_minute_aggregates
- Implement manifest builder with input/output file hashing and metadata
- Write Parquet files partitioned by venue/symbol/date under data/warehouse
- Integrate with Makefile targets: materialize-day/backfill-warehouse
- `make lint` for backend
