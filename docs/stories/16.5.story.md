# Story 16.5 — UI: Plan Preview and Start

Goal
- Show the proposed plan (universe, strategies, params, guardrails) and allow user to Start Agentic Run.

Why
- Transparency and auditability before execution.

Acceptance Criteria
- Collapsible Plan Preview panel shows included/excluded symbols with reasons, strategies, params, and guardrail results
- Start button triggers /agentic/start with plan_id
- Error states shown with actionable messages

Tasks
- Preview panel UI
- Wire to propose_plan and start endpoints
- Loading/error handling and tests

Dependencies
- Stories 16.2, 16.4
