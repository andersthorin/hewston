# Story 11.4 — Smooth visual pacing (bounded buffer + rAF)

Epic: E11 — Streaming Metrics & Synchronized Playback
Type: Performance/UX
Status: Ready for Review

User Story
- As a user, I want playback to feel smooth (no bursts), so I can read charts/metrics comfortably.

Acceptance Criteria
- Frontend decouples frame arrival from rendering using rAF-based scheduler.
- Bounded buffer (≥100) with drop-oldest policy prevents catch-up bursts.
- Visible pacing ~1h per ~150ms (≈6–8 FPS) by default; configurable via constants.
- Controls (play/pause/seek/speed) behave as before; no regressions.
- Dev monitor exposes render jitter p50/p95 and buffer size.

Technical Notes
- Worker continues to parse frames and postMessage immediately.
- Main thread buffers frames and renders 1 per tick at target cadence.
- Use requestAnimationFrame; maintain `lastPaint` per loop; gate on `playing`.
- Sync a `playingRef` to avoid stale closures; cancel rAF on cleanup.
